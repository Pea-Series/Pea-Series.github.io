隐私政策

生效日期：2026-08-09

一句话：你的文件属于你，始终留在你的设备上。

01

本地处理

PeaPlayer 与 PeaScribe 都是本地优先的桌面应用。字幕由本地 Whisper 模型生成，查词、复习与统计同样在本机完成，不依赖任何云端服务。

  • 音视频文件、字幕、生词本与学习记录全部存储在你的设备上。
  • 字幕生成、词典查询、复习排程全部在本机完成。
  • 应用无需登录，不创建云端账户。
02

我们不收集的内容

我们的设计原则是：不收集，就没有泄露。Pea 系列不采集任何使用数据。

  • 不收集姓名、邮箱等个人身份信息。
  • 不上传、不存储你的媒体文件或字幕内容。
  • 无遥测、无行为分析、无广告跟踪器。
03

网络连接

应用仅在两种情况下联网，且都由你主动发起：

  • 检查应用更新——只携带当前版本号。
  • 下载 Whisper 模型——只请求对应模型文件，不含任何媒体内容。

除此之外，应用默认离线运行。

04

第三方服务

应用不内嵌任何第三方 SDK、统计或追踪组件。

  • 可选的 Anki 导出在本地完成，数据不经过网络。
  • 安装包托管在 GitHub Releases，下载由 GitHub 提供。
05

你的数据与权利

你的积累属于你，随时可以带走。

  • SRT、CSV、Anki 等标准格式随时可导出。
  • 删除应用即删除全部本地数据，无需额外申请。
06

政策更新

若本政策发生实质变更，我们会在此页面更新，并注明新的生效日期。建议偶尔回来看看。

07

联系

如有任何疑问，欢迎通过 开发者主页 或 GitHub 与我们联系。
