Privacy · 隐私

隐私政策

适用于 macOS · Windows 生效日期：2026-08-16
我们坚持最小必要原则：只在为向你提供功能所必需时，才处理最少必要的信息。继续使用本产品即表示你已阅读并同意本政策；如不同意，请停止使用。
01

我们收集的信息类型与用途

Pea 系列是本地优先的桌面应用：你的媒体文件与字幕内容始终留在设备上；账户、支付、崩溃上报与匿名统计等信息仅在必要时处理。下表说明信息类型、使用场景、必要性，以及处理方式与保存期限。

信息类型 用途与场景 是否必要 处理方式与保存期限
设备信息（系统版本、芯片架构） 检查更新、兼容性适配 必要 仅在本机判断；联网检查更新时只携带当前版本号，不记录设备标识。
崩溃与错误信息 排查稳定性问题 可选（默认开启） 仅在崩溃或错误发生时自动上报错误信息，包含错误堆栈、系统与应用版本，不含你的媒体文件内容；可在应用设置中关闭。
账户信息（邮箱地址、账户标识） 登录、账户管理、订阅 必要 用于创建与登录账户、管理订阅；邮箱仅在账户相关事务时使用，不用于营销推广。
媒体文件与字幕内容 播放、转写、学习等核心功能 必要（仅本地） 全部在你设备上处理，不上传、不存储。
匿名使用统计 产品改进 可选（默认开启） 以去标识化的汇总数据统计功能使用频率与崩溃率，不含你的文件内容或可识别身份的信息；可在应用设置中关闭。
支付信息（账单地址、订阅状态） 处理购买与订阅 必要（支付时） 由经认证的第三方支付服务商处理，我们不在自己服务器上保存你的完整卡号。
02

存储与保护

  • 本地优先存储：你的文件、字幕、生词本与学习记录默认全部保存在你的设备上。
  • 最短保存期限：仅保留完成任务所必需的时间；本地数据由你随时清理。
  • 安全措施：网络传输走 HTTPS 加密通道；支付由经认证的支付服务商处理；应用以最小权限访问文件。
  • 存储位置：崩溃上报与匿名统计数据存储于欧盟境内的服务商；你的媒体文件与字幕内容始终留在设备上，不上传。
03

共享、转让与公开披露

  • 我们不出售个人信息；仅在提供账户、支付、崩溃上报与统计等必要功能时，与受约束的服务商共享最小必要信息。
  • 上述服务商只能按我们的指示处理数据，不得用于其他用途；除此之外，仅在法律要求或事先征得你明确同意时才可能共享。
  • 因合并、收购等原因涉及数据转让时，我们将要求接收方继续遵守本政策。
04

第三方服务与 SDK

为实现账户、支付、崩溃上报与匿名统计等功能，应用内嵌了必要的第三方服务。下表列出分发与运行所涉及的外部服务。

名称 用途 涉及的数据 网络与加密
GitHub Releases 安装包托管与下载 下载请求，不含个人信息 HTTPS 加密
Whisper 模型 本地字幕生成 模型文件，由你主动下载 本地运行，不联网
账户与认证服务 账户注册、登录与账户数据存储 邮箱、账户标识、订阅状态 HTTPS 加密存储
支付服务商 处理购买与订阅扣款 账单信息、支付结果；不包含完整卡号 HTTPS 加密 · 经认证合规
崩溃与错误上报 故障诊断与稳定性改进 错误堆栈、系统与应用版本，不含文件内容 HTTPS 加密 · 欧盟境内存储
匿名统计服务 功能使用情况与崩溃率统计 去标识化汇总数据 HTTPS 加密 · 欧盟境内存储
05

设备权限使用说明

应用仅在首次使用对应功能时申请权限，并说明用途。你可随时在系统设置中授予或撤回。

权限 用途 是否可选 撤回方式
文件读取 / 导入 导入音视频、字幕文件 可选 系统设置中随时撤销
文件写入 / 导出 导出 SRT / CSV / Anki 文件 可选 系统设置中随时撤销
其他敏感权限（如需） 对应特定功能 可选 使用前弹窗说明，可随时撤回
06

未成年人保护

本产品面向一般公众，不针对未成年人。若未成年人使用，建议在监护人指导下进行。我们不以知情的方式收集未成年人个人信息；监护人如需删除相关信息，可通过文末联系方式提出。

07

您的权利与行使方式

  • 访问与更正：本地数据由你直接管理，随时查看、修改；账户信息可在应用内或通过联系我们查看、更正。
  • 删除：删除应用或本地文件即可删除本地数据；账户及其相关云端数据可申请注销并删除。
  • 撤回同意：在系统设置中撤回文件访问等权限；在应用设置中可关闭匿名统计与崩溃上报。
  • 导出与携带：SRT、CSV、Anki 等标准格式随时可导出。
08

本政策的更新

若本政策发生实质性变更，我们会在此页面更新，并注明新的生效日期。涉及数据处理方式的重要变更，将在应用内再次提示你确认。
